# Modelo de amenazas

Amenazas cubiertas en simulación local:
- Replay de mensajes de pago.
- Manipulación de importe o firma.
- Mensajes fuera de orden.
- Productos inexistentes o sin stock.
- Timeout y desconexión.
- Reinicio durante transacción activa.

Fuera de alcance: ataques a equipos reales o redes de terceros.
