# Security policy

This project is a local, simulated IoT laboratory designed for defensive security exercises only.

## Supported scope

- Local simulator only
- No real payment systems
- No production network integration
- No offensive exploitation tooling

## Reporting concerns

If you identify a safety issue or a security concern in the simulated workflow, open an issue or discuss it through the project repository before making changes.

## Expected behavior

- Keep the system fail-secure
- Preserve audit logging
- Validate product and payment state transitions
- Reject tampered or replayed inputs
